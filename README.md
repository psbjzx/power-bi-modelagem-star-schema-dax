# Modelagem e Transformação de Dados com DAX no Power BI

Repositório destinado ao desafio da DIO de transformação da
base Financial Sample em um modelo dimensional Star Schema.

## Status

Planejado. A implementação e os arquivos do projeto serão
adicionados posteriormente.

## Objetivo

Organizar a tabela Financial Sample em tabelas fato e dimensão,
definir seus relacionamentos e criar uma dimensão de calendário
utilizando DAX.

## Etapas previstas

- [ ] Importar a base Financial Sample.
- [ ] Preservar uma cópia oculta chamada Financials_origem.
- [ ] Criar a dimensão D_Produtos com as estatísticas solicitadas.
- [ ] Criar a dimensão D_Produtos_Detalhes.
- [ ] Criar a dimensão D_Descontos.
- [ ] Criar a dimensão D_Detalhes com informações complementares.
- [ ] Criar D_Calendário utilizando a função CALENDAR em DAX.
- [ ] Criar a tabela fato F_Vendas.
- [ ] Definir e validar chaves e relacionamentos.
- [ ] Reorganizar as colunas do modelo.
- [ ] Documentar as transformações e funções DAX utilizadas.

## Entregáveis previstos

- Arquivo do Power BI no formato `.pbix`.
- Imagem do esquema em estrela.
- Documentação do processo de construção do modelo.
- Descrição das funcionalidades e expressões DAX utilizadas.

## Tecnologias previstas

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel
